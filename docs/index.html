Browser mode prototype · Local mode planned

Browser Client: Play Grimfall through the Companion WebView, with experimental controller shortcuts.

Local Client: planned 3.3.5a launcher with a required ConsolePortLK addon bundle, automatic addon setup and Thor controls. The addon bundle is not included in the current prototype yet.

Controller room

Custom buttons, analog controls, profiles, deadzones, targeting and modifier layers.

Companion rooms

Action bars, radial ability menus, character, bags, quests, maps, pets and party tools.

Thor dual-screen

Second-screen widgets, cast bars, status displays and configurable layouts.

Development status

Browser mode is a prototype. Local client runtime, ConsolePortLK bundling/installation, gameplay input and second-screen features remain unimplemented or untested.

Feature goals are inspired by the breadth of DS Forever but developed as a Grimfall-specific project.

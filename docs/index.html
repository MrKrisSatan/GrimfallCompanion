Browser controller prototype · Local runtime planned

Browser Client: Opens Grimfall in a WebView. Physical controller inputs are mapped to calibrated mobile movement, camera and action-button touch points.

Local Client: Includes a ConsolePortLK folder installer for a user-supplied 3.3.5a client. The Wine / Box64 runtime and local launch flow are not implemented.

Controller room

Calibrated touch movement and camera prototype, face-button taps, trigger modifiers and input diagnostics. Actual Thor gameplay testing remains outstanding.

Companion rooms

Planned action bars, radial ability menus, character, bags, quests, maps, pets and party tools.

Thor dual-screen

Planned second-screen widgets, cast bars, status displays and configurable layouts.

Development status

The Browser Client now has a calibrated native multi-touch controller bridge prototype. It is not yet verified against a live Grimfall session or on AYN Thor hardware.

The Local Client runtime, embedded ConsolePortLK bundle, gameplay companion and second-screen UI remain future milestones.

Feature goals are inspired by the breadth of DS Forever but developed as a Grimfall-specific project.

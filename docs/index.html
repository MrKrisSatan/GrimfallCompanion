Grimfall Companion

A handheld-first controller experience for Grimfall WoW's browser client. No full client installation required by design.

Visit GrimfallSource on GitHub

Project status

Prototype 0.1 · Input integration not hardware-tested

Our first milestone is a fullscreen WebView and experimental controller-to-keyboard bridge. We are validating the game's input path before building the second-screen interface.

Controller first

Movement, camera, ability keys, focus and reliable game input come before fancy menus.

Dual-screen vision

Eventually: configurable action bars, modifier layers, radial ability selection, targeting, and quest/map shortcuts.

Transparent & safe

No credentials stored by Companion. This is an independent community project and is not affiliated with Grimfall.

Prototype testing checklist

  • Can Grimfall's web client load in Android WebView?
  • Does WebView retain focus when physical gamepad is used?
  • Do keyboard events reach movement and camera controls?
  • Which controls require genuine touch events?
